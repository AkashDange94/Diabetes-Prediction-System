# Diabetes Prediction System

This project is a Machine Learning based web application that predicts whether a person is diabetic or not based on medical parameters.

## Features
- User-friendly web interface
- Predicts diabetes using trained ML model
- Uses patient health data as input
- Fast and accurate results

## Technologies Used
- Python
- Machine Learning
- Flask
- HTML
- CSS
- JavaScript

## Input Parameters
- Pregnancies
- Glucose Level
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## Output
- Diabetes Positive
- Diabetes Negative

## How to Run the Project
1. Clone the repository
2. Install required libraries
3. Run the Flask application
4. Open browser and enter patient details
